# Open Decks Scheduler

An SPA for generating a printable timetable for a raffle-based open decks event.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run all tests and linters
npm run check
```

## Production Build

The production build creates a **single HTML file**, `dist/open-decks-scheduler.html`, with the application code inlined and React/ReactDOM loaded from CDN:

```bash
npm run build
```
